Set up Podcast Sync

Each step checks itself and shows a check mark when it is done. Keep this page open while you work.

Checking your setup…

  1. 1

    Start the helper

    Looking for the helper…

    The helper is not running.

    The helper is a small app on your Mac. It reads Apple Podcasts for the extension. In the podcast-sync folder, run this in Terminal:

    ./scripts/install.sh

    The helper is running.

  2. 2

    Allow access to Apple Podcasts

    Do step 1 first.

    Click Allow on the macOS prompt for Podcast Sync Helper.

    The prompt asks to let it access data from other apps. This lets it read your Apple Podcasts library. It never changes the library.

    macOS does not let the helper read Apple Podcasts.

    Open System Settings → Privacy & Security and allow Podcast Sync Helper. Or run the install command again and click Allow:

    ./scripts/install.sh

    The helper can read your Apple Podcasts library.

  3. 3

    Turn on Sync Library

    Your iPhone sends its play position through iCloud. Turn on Sync Library on both devices:

    • Mac Podcasts → Settings → General → Sync Library
    • iPhone Settings → Apps → Podcasts → Sync Library

    This page cannot read this setting, so it asks you.

    Apple Podcasts on this Mac synced play positions with iCloud this week.

    Keep Sync Library on, on your iPhone too: Settings → Apps → Podcasts.

  4. 4

    Set up the iPhone shortcut

    Do step 1 first.

    Your helper is too old to check this step.

    Run the install command again to restart it:

    ./scripts/install.sh

    Looking for the Resume Podcast shortcut…

    The Resume Podcast shortcut is not in Shortcuts yet.

    This page cannot see your shortcuts. If you added Resume Podcast, you can go on.

    On your Mac, run this in the podcast-sync folder, then click Add Shortcut:

    python3 scripts/make_shortcut.py && open "shortcut/Resume Podcast.shortcut"

    Resume Podcast is in Shortcuts. iCloud copies it to your iPhone.

    You do not need this step. When you pause YouTube, the helper sends the position to your iPhone by itself.

    For a backup, add the Resume Podcast shortcut. On your Mac, run this in the podcast-sync folder, then click Add Shortcut:

    python3 scripts/make_shortcut.py && open "shortcut/Resume Podcast.shortcut"

    Run the shortcut once on your iPhone and allow its prompts. Then, in the Files app, open iCloud Drive → Shortcuts. Touch and hold the podcast-sync folder and choose Keep Downloaded.

  5. 5

    Try it

    • iPhone → YouTube Play an episode in Apple Podcasts. Then open the same episode on YouTube in Chrome.
    • YouTube → iPhone Pause the video. Then run Resume Podcast on your iPhone.

    Do step 1 first.

    Waiting for your first sync…

You are all set.

You can close this page. To open it again, right-click the Podcast Sync icon and choose Options.
